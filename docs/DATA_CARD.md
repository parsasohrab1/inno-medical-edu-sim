# کارت داده — inno-medical-edu-sim

- **منبع:** کاملاً مصنوعی؛ تولید با `python -m inno_medical_edu_sim generate --seed N` (قطعی). هیچ داده‌ی بیمار، شخص یا مرکز واقعی در ریپو نیست.
- **نمونه‌ی ذخیره‌شده:** `data/sample/*.csv` (seed=0).
- **فرض‌ها:** ۸۰ دانشجو × ۴ جلسه با توانایی نهفته (مدل پاسخ به آیتم)؛ ارزیاب انسانی نویز ندارد؛ پایایی بین ارزیاب‌ها سنجیده نشده است.
- **استفاده‌ی مجاز:** توسعه و آزمون نرم‌افزار. استفاده برای آموزش/ارزیابی مدل بالینی یا هر تصمیم واقعی مجاز نیست.
- **حریم خصوصی:** هنگام ورود داده‌ی واقعی باید بی‌نام‌سازی، مجوز اخلاق و توافق‌نامه‌ی اشتراک داده انجام شود.
