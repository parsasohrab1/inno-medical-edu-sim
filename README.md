# inno-medical-edu-sim

**آموزش و ارزیابی بالینی دانشجویان**

> وضعیت: **TRL 4** — نمونه‌ی آزمایشگاهی با اعتبارسنجی اجزا روی **داده‌ی مصنوعی** (بدون داده‌ی بیمار). برای ارزیابی بالینی یا میدانی آماده نیست. ← [مستندات TRL](docs/TRL.md)

## نیاز شناسایی‌شده
نیاز به ارزیابی عینی (OSCE) و سناریوی بالینی بدون ظرفیت کافی استاد.

## محصول
بانک سناریوی شبیه‌سازی و ارزیابی نیمه‌خودکار مهارت بالینی.

## کاربران و ذی‌نفعان
دانشکده‌ی پزشکی، مرکز مهارت‌های بالینی

## قابلیت‌های هدف
- بانک سناریوی بالینی
- چک‌لیست ارزیابی OSCE
- گزارش پیشرفت دانشجو

## داده
سناریوهای ساختگی و چک‌لیست‌های استاندارد. در مراحل اولیه فقط داده‌ی مصنوعی یا بی‌نام‌شده استفاده می‌شود.

## ریسک‌ها و محدودیت‌ها
عدالت ارزیابی؛ تأیید روایی توسط اساتید.

## مسیر پیشنهادی
1. ✅ TRL 1 → 2: تعریف نیاز و معیار موفقیت (جدول معیارها در [docs/TRL.md](docs/TRL.md)).
2. ✅ TRL 3: نمونه‌ی آزمایشگاهی روی داده‌ی مصنوعی همراه با تست.
3. ✅ TRL 4: اعتبارسنجی اجزا در آزمایشگاه با تست‌های خودکار (CI روی هر push).
4. ⬜ TRL 5: اعتبارسنجی در محیط مرتبط با داده‌ی واقعی بی‌نام‌شده — نیازمندی‌ها در [docs/TRL.md](docs/TRL.md).

## یادداشت
این ریپو بخشی از مجموعه‌ی `inno-medical-*` برای دانشگاه‌های علوم پزشکی و وزارت بهداشت است. هیچ‌یک از خروجی‌ها جایگزین قضاوت بالینی نیست.

## راه‌اندازی سریع
```bash
pip install -r requirements.txt           # فقط numpy
export PYTHONPATH=src
python -m inno_medical_edu_sim generate --out data/sample # تولید داده‌ی مصنوعی (قطعی با seed)
python -m inno_medical_edu_sim validate                   # اجرای معیارهای TRL 4 روی ۳ seed
python -m inno_medical_edu_sim demo
python -m unittest discover -s tests -v
```

## آنچه پیاده‌سازی شده
بانک ۴ سناریو، چک‌لیست OSCE وزن‌دار با آیتم‌های بحرانی (قبولی مشروط)، نمره‌ی ۱ تا ۵، گزارش پیشرفت دانشجو.
